# Provenance des exercices

## Write your own Java framework

Les sujets, squelettes, utilitaires et tests initiaux de `mapper`, `injector`, `interceptor` et `orm` proviennent du dépôt de Rémi Forax :

[forax/write_your_own_java_framework_exercices](https://github.com/forax/write_your_own_java_framework_exercices).

`COMPANION.md`, `JDBC.md`, l’illustration du sujet Interceptor et le fichier `LICENSE` proviennent également de ce dépôt. La licence Apache 2.0 d’origine est conservée à la racine.

Les modules ont été réunis en un seul projet Maven, les packages renommés sous `framework`, les liens locaux adaptés et les implémentations des parties `README.md` complétées. Les parties `README2.md` restent à travailler.

## Sujets Java Inside

Les énoncés suivants et leurs fichiers Java associés proviennent des pages d’enseignement Java Inside hébergées par l’Université Gustave Eiffel :

- [Mini JUnit — session 2, 2025](https://monge.univ-eiffel.fr/ens/IR/IR2/2025-2026/JavaInside/mini-junit.php).
- [Optimizer — session 1, 2024](https://monge.univ-eiffel.fr/ens/IR/IR2/2024-2025/JavaInside/optimizer.php).
- [Columnar — session 2, 2024](https://monge.univ-eiffel.fr/ens/IR/IR2/2024-2025/JavaInside/columnar.php).
- [Companion PDF associé](https://monge.univ-eiffel.fr/ens/IR/IR2/2024-2025/JavaInside/src/exam/COMPANION.pdf), conservé dans le package `minijunit` et référencé par les autres sujets.

Les énoncés ont été transcrits en Markdown. Les packages des utilitaires et des tests fournis ont été adaptés au projet ; les corrections ont été développées dans ce dépôt.

## Mini EventBus

Le TP blanc Mini EventBus, ses compléments Q8 à Q12, ses tests et sa correction commentée ont été créés au cours de cet entraînement. Il s’agit d’un sujet original de révision, pas d’un examen officiel.
